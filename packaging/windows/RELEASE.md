## Future Dateiverwaltung für Windows

**Installieren:** `FutureDateiverwaltung-Setup-….exe` herunterladen und ausführen. Administratorrechte sind nicht nötig, Python und alle Bestandteile sind enthalten (auch die Texterkennung für Deutsch und Englisch).

Windows SmartScreen kann beim ersten Start „Der Computer wurde durch Windows geschützt“ anzeigen, weil das Paket nicht kostenpflichtig signiert ist: **Weitere Informationen → Trotzdem ausführen**.

**Danach:** Startmenü → *Future Dateiverwaltung*. Der Browser öffnet sich mit der Oberfläche; der Einrichtungs-Assistent führt durch Computer, Festplatten und Zielordner.

- Auf den **weiteren Computern** dasselbe Paket installieren und im Startmenü *Diesen Computer als Agent einrichten* wählen.
- **Beenden:** Startmenü → *Future Dateiverwaltung beenden*.
- **Einstellungen, Datenbank, Protokolle:** `%LOCALAPPDATA%\FutureDateiverwaltung` – bleiben bei Updates und beim Deinstallieren erhalten.
- **Update:** neue Version einfach darüber installieren.

Die App liest deine Dateien nur. Sie löscht und verschiebt nichts; Kopien entstehen erst nach deiner Freigabe.
